Integration

Python package — install and search flights in under 5 minutes:

pip install picasso-redbox-sdk

# 5 lines to live flight search
from picasso import RedboxClient

client = RedboxClient(agency_id="YOUR_ID", branch="YOUR_BRANCH")
result = client.search_flights("JFK", "LHR", "2026-06-15")
